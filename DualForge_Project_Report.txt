ABSTRACT
--------------------------------------------------------------------------------

DualForge is an enterprise-grade full-stack e-commerce web application engineered to deliver a seamless, high-performance shopping experience for retail consumers while providing comprehensive inventory, order, and analytical capabilities for multi-vendor sellers and system administrators. The system directly addresses critical limitations commonly found in conventional online retail portals, including monolithic tightly-coupled architectures, stateful session vulnerabilities, weak validation of product variant selections, poor state synchronization, and static customer support.

The backend infrastructure is built using Spring Boot 3.3.4 with Java 21, implementing Spring Security paired with stateless JSON Web Tokens (JWT) to enforce granular Role-Based Access Control (RBAC) across Customer, Seller, and Admin roles. High-throughput transactional data—including users, core catalog products, carts, orders, and promotional coupons—is managed via Spring Data JPA and H2 Relational Database, while document-oriented customer reviews and feedback are persisted using MongoDB for flexible, unconstrained schema evolution.

The frontend is constructed with React 18 and Vite 5, backed by a custom vanilla CSS design system incorporating modern aesthetics like glassmorphism, responsive micro-animations, and CSS grid layouts. State management across multi-step order flows is orchestrated via React Context API. Standout technical capabilities include:
1. AI Shopping Decision Assistant which parses natural language intent, budget parameters, and key attributes to return structured recommendations.
2. Product Comparison Matrix rendering side-by-side spec tables with automated AI value analysis.
3. Smart Size Calculator utilizing body length and fit preferences to eliminate apparel/footwear sizing errors.
4. AI Coupon Optimizer auto-detecting and applying peak discount promo codes (FLAGSHIP20).
5. DualForge Trust Score (94/100) and Eco Impact Sustainability Badges enhancing consumer confidence.

Rigorous automated unit testing with JUnit 5 and Mockito, alongside comprehensive REST API validation, confirms the resilience of business transactions. The resulting system demonstrates exemplary Java Full Stack principles, scalable API design, hybrid database persistence, and cutting-edge user experience engineering.

CHAPTER 1: INTRODUCTION
--------------------------------------------------------------------------------

1.1 Purpose
The primary purpose of the DualForge Enterprise E-Commerce Platform is to engineer a modern, full-stack online retail application that bridges consumers and multi-vendor merchants within a unified, secure, and intuitive digital space. Built to serve both enterprise retail needs and end-user convenience, DualForge simplifies complex product discovery, variant selection, cart optimization, and order fulfillment while providing store administrators and sellers with robust inventory management and analytical visibility.

1.2 Scope
The system encompasses the following functional boundaries:
* Stateless Authentication & Security: User registration, password hashing (BCrypt), OTP verification, and JWT-driven Role-Based Access Control (Customer, Seller, Admin).
* Dynamic Product Catalog: Categorized item management, real-time keyword search, brand/price filters, and live stock availability badges.
* Variant & Size Protection: Mandatory size and color variant selection, category-specific size charts, and smart fit preference calculators.
* Shopping Cart & AI Coupon Optimizer: Real-time subtotal computation, automated detection of maximum discount coupons (FLAGSHIP20), and single-click coupon application.
* Order Management & Fulfillment: Multi-stage checkout workflow, order placement, status tracking (Placed, Processing, Shipped, Delivered), and historical order logs.
* AI Decision Assistant & Decision Tools: AI chatbot parsing natural language budget and feature queries, side-by-side product comparison matrix, and Shop-by-Budget bundle generators.
* Hybrid Data Persistence: Transactional JPA/H2 relational schema for core entities paired with MongoDB document persistence for flexible customer product reviews.

1.3 Problem Statement
Conventional e-commerce web applications frequently suffer from monolithic, tightly coupled server architectures, high page-reload latency, vulnerable stateful session management, rigid UI designs, high return rates due to accidental wrong-variant ordering, and unhelpful static FAQ chatbots. DualForge solves these challenges by combining a decoupled Spring Boot REST API backend with a fast React 18 Single Page Application (SPA) frontend, incorporating automated variant protection, AI shopping assistance, and dynamic budget shopping tools.

1.4 Objectives
* Objective 1: Architect a secure, stateless RESTful API using Spring Boot 3.3.4, Java 21, and Spring Security with JWT authorization.
* Objective 2: Design a modern, accessible, and responsive user interface using React 18, Vite 5, and vanilla CSS incorporating dark glassmorphism and subtle animations.
* Objective 3: Implement an AI Shopping Decision Assistant capable of parsing budget constraints and user intent from natural language inputs.
* Objective 4: Eliminate variant ordering errors by introducing mandatory pre-add selection checks, confirmation modals, and smart sizing calculators.
* Objective 5: Establish a hybrid persistence layer leveraging Spring Data JPA with H2 for transactional data and MongoDB for customer review management.
* Objective 6: Ensure system reliability through comprehensive unit testing using JUnit 5 and Mockito.

CHAPTER 2: EXISTING SYSTEM AND PROPOSED SYSTEM
--------------------------------------------------------------------------------

2.1 Existing System / Current Process
Legacy e-commerce systems typically operate on server-side rendered monolithic frameworks (such as legacy PHP or basic JSP/Servlet setups). Authentication relies heavily on server-side HTTP sessions, leading to scalability constraints. Product variant selection is often decoupled from cart validation, allowing customers to accidentally order default sizes or colors. Furthermore, customer assistance is limited to rigid static text links or basic FAQ popups.

2.2 Limitations of the Existing System
* Session Bottlenecks: Stateful session storage hampers horizontal server scaling.
* UI/UX Friction: Frequent full-page reloads degrade the shopping experience on mobile devices.
* High Order Return Rates: Unchecked variant defaults lead to incorrect size/color orders.
* Static Assistance: Basic chatbots fail to analyze user budget constraints or parse feature needs.
* Rigid Database Models: Relational database schemas struggle with unconstrained review comments and dynamic metadata.

2.3 Proposed System
DualForge introduces a decoupled architecture featuring a Spring Boot REST API and a React SPA. Authentication is completely stateless using signed JWT tokens. The platform enforces explicit pre-add variant selection, provides interactive smart size calculators based on body measurements, and offers an AI Shopping Assistant that parses queries like "I have ₹5000. I need headphones for gaming". In addition, a side-by-side comparison matrix and AI coupon optimizer maximize shopper satisfaction.

2.4 Advantages of the Proposed System
* High Performance: Single Page Application (SPA) architecture powered by Vite provides sub-second page transitions.
* Stateless & Scalable: JWT authentication allows effortless horizontal backend scaling.
* Reduced Returns: Mandatory variant alerts and smart size calculators eliminate sizing mistakes.
* Intelligent Shopping: AI Decision Assistant and Shop-by-Budget bundle makers actively guide purchase decisions.
* Hybrid Storage: Relational database ensures ACID compliance for orders while MongoDB provides flexible storage for product reviews.
